# Midlands State University Career Hub

A static Career Hub website for Midlands State University.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension. The workspace is configured to serve on port 5501.

The site links to the home page, opportunities and support, and events. Its images, videos, styles, and scripts are stored alongside the HTML files. Google Fonts and p5.js are loaded from external services.
